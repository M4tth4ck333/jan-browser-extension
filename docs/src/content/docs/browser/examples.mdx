## Core Use Cases

The Jan Browser Extension excels in several key scenarios. Here are practical examples of how to get the most out of each feature.

### Page Summarization

Perfect for quickly understanding long articles, research papers, or documentation.

<Steps>
1. **Navigate to any webpage** with substantial content
2. **Click the Jan extension icon** to open the side panel
3. **Click "Summarize Page"** or use the summarize button
4. **Review the generated summary** with key points and insights
</Steps>

![Page Summarization Example Placeholder](/assets/images/page-summary-example-placeholder.png)

**Best for:**
- Research articles and blog posts
- News articles and reports  
- Documentation and tutorials
- Long-form content that needs quick scanning

### Inline Text Assistance

Transform your writing instantly without leaving the page context.

<Steps>
1. **Select any text** on a webpage (your own writing or existing content)
2. **Wait for the tooltip** to appear near your selection
3. **Choose an action**: Rewrite, Simplify, Translate, or custom prompt
4. **Review the suggestion** and Apply, Copy, or Regenerate as needed
</Steps>

### Smart Web Search

Research topics efficiently with integrated search that provides structured results.

<Steps>
1. **Open the side panel** by clicking the extension icon
2. **Type your search query** in the chat composer
3. **Click the search button** or trigger search via chat
4. **Review structured results** with titles, links, and snippets
5. **Click links to explore** or ask follow-up questions
</Steps>

![Smart Search Example Placeholder](/assets/images/smart-search-example-placeholder.png)

**Advantages over standard search:**
- Results appear directly in your workflow
- Structured format with clean snippets  
- Can ask follow-up questions about results
- No need to open new tabs

### Context-Aware Chat with @mentions

Have conversations that reference specific tabs and content.

<Steps>
1. **Open multiple tabs** with relevant content
2. **Start typing "@"** in the chat composer
3. **Select tabs** to include in your conversation context
4. **Ask questions** that reference the selected content
5. **Get contextual responses** based on all selected pages
</Steps>

![Context Chat Example Placeholder](/assets/images/context-chat-example-placeholder.png)

**Example workflows:**
- Compare multiple product pages before purchasing
- Analyze different news sources on the same topic
- Cross-reference documentation from multiple sites
- Research academic topics across various papers

## Advanced Use Cases

### MCP Bridge Integration

For developers and power users who want to expose browser capabilities to other tools.

**Setup Example:**

```json
{
  "mcpServers": {
    "browser": {
      "command": "node",
      "args": ["/path/to/jan-browser-extension/mcp/search-server/dist/src/index.js"],
      "env": {
        "BRIDGE_HOST": "127.0.0.1",
        "BRIDGE_PORT": "17389"
      }
    }
  }
}
```

**Use cases:**
- Automated research workflows in Claude Desktop
- Integration with custom development tools
- Bulk web content analysis

## Tips for Optimal Usage

<Aside type="tip">
**Performance Tips:**
- Use lower temperature settings (0.1-0.3) for factual tasks
- Enable "Auto-follow active tab" for seamless context switching
- Pin frequently used tabs before using @mentions
- Use DuckDuckGo-only mode for faster search if Google isn't needed
</Aside>

### Keyboard Shortcuts & Efficiency

While the extension doesn't have custom keyboard shortcuts, you can optimize your workflow:

- **Tab management**: Pin important tabs before @mentioning
- **Quick access**: Pin the extension for one-click side panel access
- **Context switching**: Enable auto-follow for hands-free tab context
- **Search efficiency**: Use specific queries for better results

### Privacy Considerations

**For sensitive content:**
- Use local Jan models instead of cloud providers
- Disable auto-follow for sensitive tabs
- Clear session history regularly
- Consider turning off bridge token for air-gapped environments

### Model Selection Best Practices

**Different models for different tasks:**
- **Fast models** (like GPT-3.5) for quick summaries and simple rewrites
- **Advanced models** (like GPT-4) for complex analysis and creative writing
- **Local models** for privacy-sensitive content
- **Specialized models** for domain-specific tasks (code, creative, etc.)

## Troubleshooting Common Scenarios

**Inline assistant not appearing:**
- Ensure text selection is substantial (more than a few words)
- Check that content scripts are enabled for the current site
- Refresh pages that were open before extension installation

**Search returning poor results:**
- Try more specific queries
- Switch between DuckDuckGo and Google fallback
- Clear browser cache if results seem cached

**Context @mentions not working:**
- Verify tabs are still active and loaded
- Check that pages aren't blocked by content security policy
- Refresh tabs if they were opened before extension installation

For more detailed troubleshooting, see our [Configuration & Troubleshooting guide](./configuration).
