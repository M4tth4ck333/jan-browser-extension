## Overview

The Jan Browser companion brings AI assistance directly to your browsing experience with chat, inline writing help, search, and page context in the side panel. Connect to your local Jan installation, Cerebras, OpenAI, or any OpenAI-compatible endpoint.

### Key Features

<CardGrid>
  <Card title="Side Panel Chat" icon="chat">
    Interactive chat interface with streaming responses and session management. Automatically follows your active tab or manually select tabs for context using @mentions.
  </Card>
  
  <Card title="Inline Assistant" icon="edit">
    Select text on any page to get instant writing help via tooltip. Rewrite, simplify, translate, or adjust tone without leaving the page.
  </Card>
  
  <Card title="Smart Search" icon="magnifier">
    Integrated web search with DuckDuckGo-first approach and Google fallback. Returns structured results with links and snippets.
  </Card>
  
  <Card title="Page Summarization" icon="document">
    Quickly summarize entire pages or selected text with skimmable Markdown output rendered in the side panel.
  </Card>
</CardGrid>

### What's New in 0.12.15

- **@mention Tab Selection**: Type "@" in the composer to quickly select tabs for context
- **LIFO Tab Ordering**: Unpinned first, then most recently accessed, then rightmost
- **Overlay Sidebar**: Full-screen overlay menu for session management and quick access
- **Search Preferences**: DuckDuckGo-first with Google fallback, or DDG-only via Options
- **Model Dropdown**: Optionally fetch `/models` to pick from a list in Options

### Supported Providers

The extension works with any OpenAI-compatible API endpoint:

- **Jan (Local)** - `http://localhost:1337/v1`
- **Jan Server (Cloud)** - `https://comingsoon.ai`
- **Cerebras** - `https://api.cerebras.ai/v1`
- **OpenAI** - `https://api.openai.com/v1`
- **Custom endpoints** - Any OpenAI-compatible base URL

### MCP Bridge Integration

<Aside type="tip">
For developers and power users, the extension includes an optional MCP (Model Context Protocol) bridge that exposes search and visit tools to LLM clients like Claude Desktop.
</Aside>

The extension can function as an MCP server, providing:
- **Web Search** - Google SERP scraping with structured results
- **Page Visit** - Content extraction from URLs
- **Bridge Status** - Connection monitoring tools

![MCP Bridge Architecture Placeholder](/assets/images/mcp-bridge-placeholder.png)

### Privacy & Security

- API keys stored locally in Chrome storage (sync)
- Optional bridge token authentication for MCP connections
- Targeted, user-initiated searches only - no background crawling
- Support for local-only processing with Jan local models

### Architecture

The extension follows a three-component architecture:

- **Background Service Worker** - Central router for API calls, search tools, and MCP bridge
- **Content Script** - Page extraction, text selection, and inline assistant tooltip
- **Side Panel UI** - React-based chat interface with streaming Markdown rendering

For technical details, see the [agents guide](https://github.com/menloresearch/jan-browser-extension/blob/main/agents.md).
